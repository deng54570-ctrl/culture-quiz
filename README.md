# 中外文化交流史 · 填空刷题

一个**单文件网页**的刷题程序。手机上打开即用，可「添加到桌面」，离线也能跑（不联网、不依赖任何外部资源）。

## 题库

**981 题 / 1061 空**（901 个不同考点），来自 7 份《中外文化交流史》填空练习（含答案版）：

| 板块 | 题目 | 空数 |
|---|---:|---:|
| 第二～四章（丝路源流、西学东渐） | 86 | 109 |
| 中越老柬文化交流 | 108 | 115 |
| 中日文化交流 | 139 | 143 |
| 中韩(朝)文化交流 | 152 | 155 |
| 中泰文化交流 | 78 | 80 |
| 中缅·中国印尼·中印文化交流 | 214 | 227 |
| 丝绸之路·中国与伊朗、阿拉伯世界文化交流 | 204 | 232 |
| **合计** | **981** | **1061** |

每题都标注了所属板块与题号；多空题（99 道）会按「第 1 空 / 第 2 空…」逐空作答。

### 挖空原则

- **只挖实词**：往来器物、人名、书名、地名、制度术语。原题里挖「年份／数量」的空全部还原成陈述句（如 `共任命________次` 这类），全篇没有一个是数字空。
- 题干里出现、又本身就是考点的《书名》会补挖（如 `据《岛夷志略》记载` → `据《________》记载`）。

### 干扰项原则

选择题的 3 个干扰项按**词槽**（空左右两侧的语境）从教材原文里找同类词，而不是同章随机抽：

| 来源 | 占比 | 说明 |
|---|---:|---|
| 库内同词槽 | ~24% | 别处考点，处在同一词槽（如 `…________时代` / `…________帝国`） |
| 原文同词槽 | ~18% | 从教材原文里按同一词槽挖出的同类词 |
| 书名 | ~15% | 答案是《书名》时，选项全是别的书名 |
| 同类词尾 | ~8% | 同板块、同结尾类别字（寺／馆／教／族／人…） |
| 同章兜底 | ~35% | 该词槽在教材里确实只有一两个词时的退路 |

效果举例：`上古`→奈良／弥生／东晋（都是时代）；`张骞`→常骏／康泰／王君政（都是遣使的人）；`诸蕃志`→岛夷志略／星槎胜览／大藏经（都是书）。

仍然不是每题都完美：教材里某个词槽本来就只有一个词的题，兜底项会偏弱。


## 三层逻辑（v3 起）

这版不只是皮肤，底层换了三件事：

### ① 记忆排程：程序决定你今天做什么
每题有自己的**熟练度**和**到期时间**。

- 答对 → 熟练度 +1，下次间隔按 `10分 → 1天 → 3天 → 7天 → 16天 → 35天 → 70天` 顺延
- 答错 → 熟练度 -2，10 分钟后重新出现
- 首页「今日」显示**今天到期多少空**，点一下就开始；你不再需要手选 20/50 题

### ② 考点树：按「容易混」重新组织题目
901 个考点归成 **11 个大类 / 72 个组**（小组、游记行纪、求法僧、来华僧、城市港口、香药香料…）。

- 「考点」页：大类 → 组 → 考点，能看到同一个考点散在各板块的**全部**空格
- 每组一个「**对比练**」按钮：把这一组连着做，专治张冠李戴
  （例：《岛夷志略》在中伊、中泰、中缅印尼 3 个板块被考了 11 次）

### ③ 错因与薄弱画像
答错时，程序会看**你选的那个错项属于哪一类**，反推错因：

| 错因 | 含义 |
|---|---|
| 同一组里混了 | 正确项和你的错选在同一组（如《星槎胜览》↔《瀛涯胜览》） |
| 同类不同组 | 同大类不同组（如《三国演义》↔《大藏经》都属典籍文献） |
| 跨类记混 | 完全不同的类别 |
| 没写出来 / 记了个形近的 / 记岔了 | 默写模式下的判定 |

按组累计，首页「薄弱画像」显示你在哪几组上错得最多。

## 记录安全

所有记录存在浏览器本地（localStorage），**换设备或清缓存会丢**。

- v2 的老记录（`cq_v2_*`：进度／错题本／收藏／笔记／历次记录）**全部保留且仍在读取**，不会因为这次改版丢失
- 新增的记忆数据放在 `cq_v3_*` 键下，首次打开会**从老记录迁移**出初始熟练度
- 题库只做**追加**：老题目的 id、答案、选项一字未改（可用 `_work/` 下的备份逐条 diff 验证）

## 怎么用

直接用浏览器打开 `index.html`，或在手机上用文件管理器打开。

1. **选作答方式**：`选择题（点选项）` 或 `填空默写（打字）`。
2. **选抽题范围**：全部 / 未做过 / 错题本 / 收藏；点板块（选中单个板块还会展开章节）缩小范围。
3. **选顺序与题量**：随机或按顺序；20 / 50 / 100 / 全部。
4. 开始刷题 —— 答完立刻判对错、给出正确答案，答错的自动进错题本。

底部五个页签：**刷题 / 错题本 / 收藏 / 笔记 / 统计**。

所有记录（进度／错题本／收藏／笔记／历次记录）只存在**这台设备的浏览器**里（localStorage），不上传；换设备或清缓存会丢。

- **上一题**：答完可以随时点「← 上一题」回去看（键盘 `←`／`→` 也行）。回去时**当时的作答会原样还原** —— 你选错的那项、正确项、判分反馈都还在，不是重新出题。
- **计时器**：进度条右边一直显示这一轮做了多久，做完后成绩里也会写出用时。
- **中途能走、回来接着做**：答到一半点「结束」或者直接关页面，进度都存着。下次打开首页会多一张「⏸ 上次还没做完」的卡片，写清已作答多少、正确率、已用多久，点「继续做」就接着走（当时的对错、当前位置全都还原）。不想留了才点「放弃这一轮」。
- **笔记（默认收起）**：每答完一道，题卡下方只有一条「📝 记笔记」按钮 —— **不需要记就不占地方**。想记才点开，写完收起；已经写过的笔记会直接显示正文。笔记页汇总全部笔记（新的在前），可「只看这道」跳回去重做，也可删除、导出成 Markdown。
- **历次记录**：统计页记录每一轮「错几个 / 正确率 / 用时 / 范围」，第 1 轮错多少、第 2 轮错多少一眼能比，并标出「首次」和「最少」那轮。
- **错题本**：答错的自动收进来；重做时答对就自动移出。可「重做全部」，也可只做某一道。
- **收藏**：答题时点左下角 ☆ 收藏，随时在收藏页复习。
- **统计**：累计答对、正确率、各板块进度，以及清空记录。

所有记录（进度／错题本／收藏／笔记）只存在**这台设备的浏览器**里（localStorage），不上传；换设备或清缓存会丢。

## 键盘

- 选择题：`1`–`4` 或 `A`–`D` 直接选（点选项也行）。
- 填空：回车提交，再回车下一题。
- `←` / `→`：上一题 / 下一题。
- `Esc` 结束本轮。

## 重新生成

题库是从 6 份 docx 解析出来的，改题/换题只需改解析结果再重建：

```bash
# 1. 改 _work/build_bank.py 里的 FILES 路径或解析逻辑
# 2. 重新生成题库 + 注入 HTML
python3 _work/build_bank.py     # -> _work/bank.json
python3 _work/build.py          # bank.json -> index.html
# 3. 跑一遍回归测试（无头 Chrome）
python3 _work/mk_test.py        # 生成 _work/test.html，用浏览器打开看结果
```

`app.template.html` 是页面模板，`index.html` 是注入题库后的成品（**要交付/分享的就是它**）。

## 数据格式

`_work/bank.json` 里每个「空」是一条 item：

```js
{ id:'中泰-2-0', book:'中泰', chapter:'第八章　…', num:2, bi:0, bn:2,
  stem:'…派遣使臣________、________出使赤土…',
  answer:'常骏', alts:['常骏'], options:['常骏','王君政','那邪迦','阿彻多'] }
```
