# 中外文化交流史 · 填空刷题

单文件网页的刷题程序：850 题 / 885 空，来自 6 份《中外文化交流史》填空练习（含答案版）。

- 两种作答方式：**选择题**（4 选 1，干扰项取自同章答案）/ **填空默写**（忽略空格大小写，括号别名算对）
- **错题本**：答错自动收录，答对自动移出；可重做全部或单题
- **收藏**：随时 ☆ 收藏、整组复习
- **统计**：累计答对、正确率、各板块进度
- 记录只存在本机浏览器（localStorage），不上传
